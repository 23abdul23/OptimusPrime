# ADR-012: Reasoning Agent

- Status: Accepted and implemented in Phase 11
- Phase: 11

## Context

The previous final step was a synthesis service, but not yet an explicit reasoning boundary.

That left answer generation too thinly specified relative to:

- evidence confidence
- graph context
- provenance highlights
- graph actions already chosen by retrieval

## Decision

Introduce `ReasoningAgentService` as the grounded answer-generation boundary.

Responsibilities:

- grounded synthesis
- explicit confidence framing
- graph explanation
- evidence-aware fallback generation

Graph actions remain generated by retrieval/graph-analysis, while the reasoning agent consumes them as context for the final answer.

## Consequences

- answer generation is now a distinct runtime role
- evidence confidence and provenance are incorporated directly into the reasoning prompt
- the backend matches the documented “Reasoning Agent” architecture role more closely

## Implementation Notes

Phase 11 introduces `ReasoningAgentService` and rewires orchestration to use it instead of the old synthesis-only service.
